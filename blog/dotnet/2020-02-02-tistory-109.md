# 집계 작업 Aggregators

집계 작업 은 집합 모든 요소를 계산하여 하나의 값으로 반환하는 작업입니다. 집계 작업에 해당하는 LINQ 메서드로는 Count , Sum , Min , Max , Average , Aggregate 가 있습니다.

# Sum

## 집합 내 모든 원소 더하기

```
int[] numbers = { 5, 4, 1, 3, 9, 8, 6, 7, 2, 0 };

            double numSum = numbers.Sum();

            // numSum = 45
```

## 집합 내 원소를 활용하여 더하기

```
string[] words = { "cherry", "apple", "blueberry" };

            double totalChars = words.Sum(w => w.Length);

            // totalChars = 20
```

words 배열의 string 원소 길이를 사용하여 전체 문자 개수를 파악합니다.

```

products = GetProductList(); var categories = from p in products group p by p.Category into g select (Category: g.Key, TotalUnitsInStock: g.Sum(p => p.UnitsInStock)); ``` Category 별로 그룹을 만든 후, Category 그룹 내 Product의 UnitsInStock을 모두 더합니다.
