## Range

[Rnage](https://docs.microsoft.com/en-us/dotnet/api/system.linq.enumerable.range?view=netframework-4.8) 메서드는 특정 범위의 숫자 집합을 만들 때 사용하는 메서드입니다.

> System.Collections.Generic.IEnumerable Range (int start, int count)

start 부터 count 만큼 숫자 범위 집합을 생성합니다.

```
var numbers = from n in Enumerable.Range(100, 50) // 100 - 149 까지
                          select (Number: n, OddEven: n % 2 == 1 ? "odd" : "even");
```

## Repeat

[Repeat](https://docs.microsoft.com/en-us/dotnet/api/system.linq.enumerable.repeat?view=netframework-4.8) 메서드는 특정 숫자를 특정 횟수만큼 반복한 집합을 만들 때 사용하는 메서드입니다.

> System.Collections.Generic.IEnumerable Repeat (TResult element, int count)

element를 count 만큼 반복한 집합을 생성합니다.

```
var numbers = Enumerable.Repeat(7, 10);
            // numbers = { 7, 7, 7, 7, 7, 7, 7, 7, 7, 7 };
```
