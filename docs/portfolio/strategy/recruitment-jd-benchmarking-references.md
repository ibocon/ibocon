# 국내 개발자 채용 직무(JD) 레퍼런스 벤치마킹 분석서

---

## 1. 개요 및 수집 목적

* **문서명**: 국내 개발자 채용 직무(JD) 레퍼런스 벤치마킹 분석서
* **관리 위치**: `docs/portfolio/strategy/recruitment-jd-benchmarking-references.md` (Local SoT)
* **수집 플랫폼**: 사람인(Saramin), 점핏(Jumpit), 잡플래닛(Jobplanet), 원티드(Wanted), 랠릿(Rallit)
* **수집 목적**:
  1. 국내 IT/테크 기업 채용 공고의 실제 자격 요건과 우대 사항을 전수 조사하여, 김예건 님의 9년 차 엔지니어링 이력(41개 Git 저장소)이 가장 매력적으로 보일 수 있는 **직무 직결형 노션 정보 구조([조합 4])의 실증적 근거**를 수립.
  2. HR 채용 담당자, 헤드헌터, 테크 리드가 사용하는 **핵심 검색 키워드(C# .NET 백엔드, K8s GitOps 인프라, Windows 데스크톱, BLE IoT 모바일)**와 1:1로 일치하는 포트폴리오 디렉터리 체계 도출.

## 4. 결론 및 향후 활용 계획

1. **HR/리크루터 3초 스캔 최적화**:
   - 채용 담당자가 지원자의 노션 사이드바를 보는 순간 채용 공고(JD)의 요구 직무와 100% 매칭되어 서류 전형 통과율이 극대화됨.
2. **생소한 프로젝트명 차단**:
   - `Monolith`, `Argon`, `Peony`, `Lithium` 같은 사내 코드명 대신 공고 키워드인 `전사 백엔드`, `K8s GitOps`, `데스크톱 클라이언트`, `BLE IoT 모바일`이 먼저 각인됨.
3. **SoT 연계**:
   - 본 분석서를 `resume/` 내에 영구 보존하고, 향후 이력서 및 경력 기술서 작성 시 각 공고별 요구 역량에 맞춰 본문의 STAR 기술서를 조율하는 레퍼런스로 활용함.
