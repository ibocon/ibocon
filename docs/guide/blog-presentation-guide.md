# 블로그 표시 품질 가이드

## 이 가이드를 쓰는 때

새 글에 그림이나 커버를 넣을 때, 글 페이지 간격을 고칠 때, 화면에서 "답답하다"거나 "글자가 작다"는 느낌이 들 때 쓴다. 검사 가능한 규칙은 [표시 품질 컨벤션](../convention/blog-presentation.md)에 있다.

## 그림이 작아 보일 때

1. 먼저 그림의 방향을 본다. `LR`로 노드와 subgraph를 나열하면 폭이 커져 본문 폭에 맞춰 줄고, 그만큼 글자가 작아진다.
2. 흐름이 3단계를 넘거나 subgraph가 둘 이상이면 `TB`로 바꾼다.
3. 한 줄 라벨이 24자를 넘으면 역할어로 줄이거나 `<br/>`로 나눈다.
4. 그래도 크면 그림을 둘로 쪼갠다. 한 그림은 질문 하나만 설명한다.

예시: Postfix 글의 그림 1은 `LR`에서 `TB`로 바꾸자 렌더 폭이 1136px에서 538px로 줄어 본문 폭(약 736px) 안에 들어왔고, 글자가 원본 크기로 보였다.

## 라벨을 줄이는 방법

| 줄이기 전 | 줄인 뒤 | 이유 |
| --- | --- | --- |
| `load balancer node port ingress gateway` | `LB · NodePort · Ingress` | 영문 나열을 약어로 줄이고 본문에서 구성요소를 설명한다. |
| `외부 요청이 내부에서 온 것처럼 신뢰되는 주소 변환 지점` | `주소 변환 지점<br/>내부로 오인` | 두 줄로 나눈다. |

둘째 행은 설명용 예시이며 실제 글의 문구와 같지 않아도 된다.

## 커버 이미지

1. 가장자리까지 채운 SVG는 최상위 그룹으로 감싸 86% 안팎으로 줄여 가장자리 10% 이상을 비운다. 예: `<g transform="translate(84 44.1) scale(0.86)">…</g>`
2. CSS는 자르지 않는다. 새 비율의 커버를 쓰려면 컨벤션과 policy의 `viewBox`·`aspect-ratio`를 함께 바꾼다.

## 간격

1. 새 간격 값이 필요하면 px을 직접 쓰지 말고 `--space-*` 토큰 중 가까운 값을 쓴다.
2. 제목 앞이 좁아 보이면 해당 규칙이 아니라 `--flow-heading` 토큰을 조정한다.
3. 좁은 화면에서만 줄이고 싶으면 `@media`에서 흐름 토큰 값만 바꾼다.

## 작성 순서

1. 글을 쓰고 그림과 커버를 만든다.
2. `pwsh -NoProfile -File site/scripts/Test-BlogPresentationConvention.ps1`을 실행해 진단을 해소한다.
3. `pwsh -NoProfile -File scripts/Start-BlogSite.ps1`로 localhost를 열어 아래 체크리스트를 확인한다.

## 화면 검토 체크리스트

- 글 머리(배너·태그·제목·커버)가 한 덩어리로 붙어 보이지 않는가?
- 제목이 앞 문단과 충분히 떨어져 구분되는가?
- 그림의 글자가 본문 글자만큼 읽히는가?
- 커버 그림이 가장자리에 붙거나 잘려 보이지 않는가?
- 좁은 화면(모바일 폭)에서도 위 항목이 유지되는가?

검사를 통과해도 위 항목이 어긋나면 글이 아직 끝난 것이 아니다.
